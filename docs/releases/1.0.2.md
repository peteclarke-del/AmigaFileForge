# Amiga File Forge 1.0.2

Amiga File Forge 1.0.2 corrects Linux desktop icon registration in the native
Debian and Ubuntu packages.

## Changes

- Added 48, 64, 128 and 256 pixel PNG application icons alongside the scalable
  SVG, covering launchers that do not reliably resolve SVG-only theme entries.
- Registered the icon under the conventional `amiga-file-forge` theme name and
  supplied a `/usr/share/pixmaps` fallback, avoiding stale reverse-DNS icon
  cache entries in GNOME Shell.
- Set the GTK window icon explicitly and added the matching X11 startup class,
  allowing GNOME, Ubuntu Dock and X11 window managers to associate the running
  application with its desktop entry.
- Refresh both GTK 3 and GTK 4 hicolor caches after package installation,
  upgrade and removal.
- Apply the same icon installation and cleanup rules to checkout-based native
  installations.
- Added regression checks for the packaged icon set, desktop identity and
  native window configuration.

## Linux packages

The release provides packages for Debian 13 and Ubuntu 24.04 on AMD64, ARM64
and ARMv7. Choose the file matching both the operating system and processor.
For example:

```bash
sudo apt install ./amiga-file-forge_1.0.2-1~deb13_amd64.deb
```

The packages include the native GTK launcher, desktop integration and the
bundled HxCFloppyEmulator runtime for HFE media.

Installing 1.0.2 over 1.0.1 preserves native XDG workspace data and Docker
working volumes. Save important open images before upgrading.

See the [installation guide](../INSTALLATION.md) and
[Linux desktop guide](../LINUX-DESKTOP.md) for setup and troubleshooting.
