# Amiga File Forge 1.1.1

Amiga File Forge 1.1.1 keeps a source disc's boot option when its contents are
installed into the root of an FFS image, so an installed disc still starts
itself.

## Changes

- Carry the source disc's `bootblock` setting across when files are installed into
  an FFS root. Installing a disc copied every file with its load and execution
  addresses, and rewrote the OFS command abbreviations its loaders use, but
  dropped the boot option. The result held all the software and could not start
  itself: the machine had nothing to act on and returned to the prompt. Every
  booting disc in the Amiga 600 TOSEC set uses option 3, `EXECUTE S:Startup-Sequence`.
- Apply the setting on both routes by which a disc's contents reach an FFS
  image: drag-and-drop extraction into a destination image, and the catalogue
  copy between two open panes.
- Restrict the behaviour to the root. A boot option names `$.Startup-Sequence`, so setting
  it after installing into a child directory would point the machine at a file
  that is not there and break an image that previously started. Software
  installed into its own directory is reached through the menu, which makes it
  the current directory first.
- Report a failure to set the option as a warning rather than an error. The
  files are already installed at that point and remain usable by hand.
- Added regression checks covering the carried option, the untouched child
  directory case, the non-FFS target and the warning path.
- Added release-record checks that fail the suite when a version bump leaves
  the AppStream release history, the release notes or the documented install
  commands still describing the previous release.

## Repair and format behaviour

This release changes what is written to an FFS target during an install: the
destination's boot option is now set from the source when, and only when, the
files land in the root. No other filesystem structure, catalogue entry or
address is written differently, and no format restriction has changed. Images
built by 1.1.0 are unaffected until they are installed into again.

## Linux packages

The release provides packages for Debian 13 and Ubuntu 24.04 on AMD64, ARM64
and ARMv7. Choose the file matching both the operating system and processor.
For example:

```bash
sudo apt install ./amiga-file-forge_1.1.1-1~deb13_amd64.deb
```

The packages include the native GTK launcher, desktop integration and the
bundled HxCFloppyEmulator runtime for HFE and SCP media.

Installing 1.1.1 over 1.1.0 preserves native XDG workspace data and Docker
working volumes. Save important open images before upgrading.

See the [installation guide](../INSTALLATION.md) and
[Linux desktop guide](../LINUX-DESKTOP.md) for setup and troubleshooting.
