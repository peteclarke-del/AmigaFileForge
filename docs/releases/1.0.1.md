# Amiga File Forge 1.0.1

Amiga File Forge 1.0.1 is a focused maintenance release for the web and native
Linux editions. It adds a proper About view and keeps the packaged version,
handbook and release metadata aligned.

## Changes

- Replaced the single Help button with a compact Help menu containing the
  handbook and About actions.
- Added an About dialog that reports the running application version, web or
  native host edition, Amiganut filesystem engine, supported media families and
  target Amiga platforms.
- Added direct project, issue tracker, contribution and third-party notice
  links, together with the MIT licence summary.
- Kept the dialog keyboard accessible and usable in both light and dark themes.
- Added JavaScript regression coverage for the Help menu and live About data.

## Linux packages

The release provides packages for Debian 13 and Ubuntu 24.04 on AMD64, ARM64
and ARMv7. Choose the file matching both the operating system and processor.
For example:

```bash
sudo apt install ./amiga-file-forge_1.0.1-1~deb13_amd64.deb
```

The packages include the native GTK launcher, desktop integration and the
bundled HxCFloppyEmulator runtime, built for each architecture and used for HFE
media.

## Upgrade notes

The package is a direct upgrade from 1.0.0. Existing native XDG workspace data
and Docker working volumes remain compatible. Save important open images before
upgrading, as with any application update.

See the [installation guide](../INSTALLATION.md) and
[Linux desktop guide](../LINUX-DESKTOP.md) for setup and troubleshooting.
