## Generated-media and fault-injection gate

The final workflow implementation was then checked with the focused release
gate:

```sh
python -m unittest \
  tests.test_generated_media_matrix \
  tests.test_failure_injection \
  tests.test_workflow_recipe -v
```

Result: 14 tests passed with no skips or failures in 131.778 seconds.

This generated and reopened every core format, exercised writable filesystems,
HDF slot shape, Kickstart ROM recovery, AmigaDOS directory capabilities, big
directories and HDF offsets. Fault injection covered interrupted upload,
partial-write rollback, full OFS media and corrupt catalogues. The workflow
gate built a real OFS recipe bundle, applied its guarded patch to the recorded
base and verified the deterministic replay output hash.
